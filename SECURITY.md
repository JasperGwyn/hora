# Seguridad

Hora corre en tu máquina y guarda el estado en local. No envía datos a ningún servidor.

Si encontrás una vulnerabilidad, abrí un [issue privado de seguridad](https://github.com/JasperGwyn/hora/security/advisories/new) en vez de un issue público. Si eso no está disponible, escribí a quien mantiene el repo por GitHub.
